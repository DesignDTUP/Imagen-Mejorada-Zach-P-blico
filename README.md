# Mejor Imagen Público Zach

48 imágenes fuente `01_Portada`, correspondientes a 19 familias de productos. Objetivo: 144 imágenes, tres por cada presentación o aroma.

Cada carpeta conserva la jerarquía de producto, presentación y aroma del origen.

- `01_Ecommerce.png`: fotografía principal de fondo blanco.
- `02_Creativa.png`: estilo aleatorio registrado en inventario.csv.
- `03_Creativa.png`: otro estilo aleatorio distinto de la secundaria.

Herramienta utilizada: Crear imagen integrada (image_gen), sin API ni CLI.

Estado actual: tres borradores de Rompe Grasas 4 L generados. Las otras 47 fuentes siguen pendientes. Las etiquetas generadas presentan diferencias en texto pequeño: los borradores no están validados para uso comercial.

Repositorio público: https://github.com/DesignDTUP/Imagen-Mejorada-Zach-P-blico
